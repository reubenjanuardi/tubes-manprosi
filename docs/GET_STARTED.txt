🎯 KEY ENDPOINTS

After server running at http://localhost:8000:

1. Submit Contact Form
   POST http://localhost:8000/api/contact

2. Submit Assessment
   POST http://localhost:8000/api/assessment
   (with files!)

3. Get Assessment
   GET http://localhost:8000/api/assessment/{id}

4. Download PDF
   GET http://localhost:8000/api/assessment/{id}/export/pdf

5. Download Excel
   GET http://localhost:8000/api/assessment/{id}/export/excel

🔧 TROUBLESHOOTING

Problem: MySQL not running
→ Open Laragon, click MySQL to start

Problem: "Command not found" 
→ Make sure you're in right directory (backend folder)

Problem: Port 8000 already in use
→ Run: php artisan serve --port=8001

Problem: "SQLSTATE database not found"
→ Run: php artisan migrate

Problem: Files not uploading
→ Run: php artisan storage:link

🧪 TEST IT

Option 1: Browser Console Test
  1. Open client/index.html in browser
  2. Press F12 (Open DevTools)
  3. Go to Console tab
  4. Type: testApiConnection()
  5. You should see "API connection test PASSED"

Option 2: Use Postman
  1. Download Postman
  2. Create new request
  3. Method: POST
  4. URL: http://localhost:8000/api/contact
  5. Headers: Content-Type: application/json
  6. Body: {"institution":"Test","fullname":"User","email":"test@test.com","service_type":"Test","message":"Hi"}
  7. Click Send
  8. Should see success response
