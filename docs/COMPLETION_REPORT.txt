🚀 QUICK START INSTRUCTIONS
──────────────────────────────────────────────────────────────────────────────

OPTION 1: Automated Setup (Recommended)
  1. Open PowerShell in TUBES_MANPROSI directory
  2. Run: powershell -ExecutionPolicy Bypass -File QUICK_START.ps1
  3. Wait for completion
  4. Run: cd backend && php artisan serve
  5. Backend ready at http://localhost:8000

OPTION 2: Manual Setup
  1. cd c:\laragon\www\TUBES_MANPROSI\backend
  2. composer install
  3. copy .env.example .env
  4. php artisan key:generate
  5. php artisan migrate
  6. php artisan storage:link
  7. php artisan serve

OPTION 3: Using Laragon (Windows)
  1. Open Laragon
  2. Start MySQL
  3. Navigate to backend folder
  4. Double-click artisan → serve

Frontend Integration:
  1. Copy content dari API_INTEGRATION_SNIPPET.js
  2. Paste ke client/app.js
  3. Update: const API_BASE_URL = 'http://localhost:8000/api';
  4. Call: initializeApiIntegration(); in DOMContentLoaded

Testing:
  1. Open http://localhost:8000 (backend info page)
  2. Open browser console (F12)
  3. Run: testApiConnection();
  4. Should return success message
