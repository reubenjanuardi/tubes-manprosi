## 🎯 API ENDPOINT SUMMARY

### Authentication Required Endpoints
All endpoints under `auth:sanctum` middleware require Bearer token in header:
```
Authorization: Bearer {your_token_here}
```

### Token Lifecycle
1. **Register/Login** → Receive token
2. **Store token** → Use for authenticated requests
3. **Logout** → Token revoked, must login again
